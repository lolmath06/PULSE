# Showcase pipeline

Regenerates the media used by the repository README: screenshots, the hero,
the GitHub social preview, the animated demo and the MP4 product video.

**Showcase tooling only.** Nothing here is part of PULSE, imported by it or
bundled with it, and the application's own code is not modified to produce
these images.

## How it works

1. `pnpm build` produces the real, unmodified PULSE frontend in `dist/`.
2. The scripts serve it with `vite preview` and open it in headless Chromium
   through [Playwright](https://playwright.dev).
3. Before any application code runs, [`fixture/backend.js`](fixture/backend.js)
   is injected as `window.__TAURI_INTERNALS__` — the same seam the Tauri
   webview provides. The real React components, layouts and styles then talk
   to it exactly as they talk to the Rust backend.
4. Every state is reached by clicking through the real interface: the welcome
   sheet, the sidebar, the template gallery, the process table.

### The fixture

- **The machine is fictional.** An 8-core / 16-thread CPU, one NVIDIA
  GeForce RTX 4070, a "PULSE Demo" NVMe and SATA SSD, Ethernet and Wi-Fi with
  locally administered MAC addresses, Fedora Linux 39 on Wayland. No value
  comes from the host the capture runs on.
- **The catalog is PULSE's own.** [`fixture/catalog.json`](fixture/catalog.json)
  is generated by [`catalog/`](catalog), a tiny Rust program that includes
  `src-tauri/src/{metrics,platform,…}` by path (like `tools/windows-check`)
  and calls the real metric declaration functions for that fictional
  hardware. Every display name, description, unit, kind and availability is
  therefore exactly what the backend would declare.
- **Readings are deterministic.** Values are pure functions of time (seeded
  value noise and irregular activity episodes — a build, a download, a render),
  with consistent relationships: memory used = total × usage, temperatures lag
  load, process rows match the counts. There is no randomness.
- **Backend strings are verbatim.** Overlay backend and capability texts are
  copied from `src-tauri/src/overlay/`, so the Overlays page says what the real
  backend says for a GNOME Wayland session with the bridge active.
- **Nothing acts.** Process controls and "open in browser" commands answer
  `unsupported` and do nothing.
- **Time is pinned.** Every capture starts at 2026-09-15 14:32 UTC (Playwright
  clock), in the `en-US` locale and the UTC time zone.

## Prerequisites

- Node.js 20.19+ and pnpm (as for PULSE itself), `pnpm install` done at the
  repository root.
- **ffmpeg** with `libwebp` and `libx264` (WebP and H.264 encoding).
- **ImageMagick** (`convert`) for the social preview PNG.
- A Chromium build for Playwright: `npx playwright-core install chromium` once,
  or point `SHOWCASE_CHROMIUM` at an existing Chromium / Chrome executable.
- Optional, recommended: the **Inter** font installed system-wide. PULSE asks
  for Inter first; without it the system fallback font is used and captures
  will look slightly different.
- Optional: Rust (only to regenerate `fixture/catalog.json`).

## Install

```bash
npm install --prefix scripts/showcase
```

This installs only `playwright-core` into `scripts/showcase/node_modules/`;
PULSE's own dependencies and lockfile are untouched.

## Commands

Run from the repository root, after `pnpm build`:

| Command                                 | Generates                                                               | Time  |
| --------------------------------------- | ----------------------------------------------------------------------- | ----- |
| `node scripts/showcase/screenshots.mjs` | `docs/assets/screenshots/*.webp`                                        | ~1 m  |
| `node scripts/showcase/branding.mjs`    | `docs/assets/branding/pulse-hero.webp`, `pulse-social-preview.png`      | ~30 s |
| `node scripts/showcase/demo.mjs`        | `showcase-output/Pulse-demo.mp4` and `docs/assets/demo/pulse-demo.webp` | ~2 m  |

To regenerate the fixture catalog after a change to the metric declarations:

```bash
cargo run --manifest-path scripts/showcase/catalog/Cargo.toml \
  --target-dir showcase-output/cargo > scripts/showcase/fixture/catalog.json
pnpm exec prettier --write scripts/showcase/fixture/catalog.json
```

## The compositions

The hero, the social preview and the video's title cards and captions are
small HTML layouts ([`branding/frame.css`](branding/frame.css)) styled with
PULSE's Clean tokens and the real logo (`public/pulse.png`). They embed a real
capture of the app; they never draw application UI themselves. In the video,
captions are composited by ffmpeg over the recorded frames — nothing is
injected into the application page.
