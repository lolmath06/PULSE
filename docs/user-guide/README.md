# PULSE User Guide

> Status: Phase 0. PULSE does not monitor anything yet — this guide grows with
> the features.

## What PULSE is

A modular, cross-platform system monitoring dashboard for **Windows** and
**Fedora Linux**. It is designed to be configured rather than merely used:
dashboards, widgets, layouts and themes are all meant to be yours.

## What exists today

The application shell: a dark interface with five sections, and a status bar
reporting the platform detected by the backend. Every section other than
Overview is a placeholder.

| Section         | Today                         | Eventually                                 |
| --------------- | ----------------------------- | ------------------------------------------ |
| **Overview**    | Detected platform information | The default dashboard                      |
| **Gaming**      | Placeholder                   | Low-overhead in-game monitoring            |
| **Development** | Placeholder                   | Build and workload pressure                |
| **Personal**    | Placeholder                   | A freely composable dashboard, 20+ widgets |
| **Mini**        | Placeholder                   | Settings for the permanent desktop overlay |

## Installing

There are no installers yet. To run PULSE from source, see
[`../development/getting-started.md`](../development/getting-started.md).

## Coming later

Real CPU, GPU, memory, storage, network and sensor monitoring; real-time and
historical graphs; configurable dashboards; movable, resizable widgets; the
Mini overlay; alerts; themes and presets; multi-monitor support; a tray icon;
autostart; and packaged installers for Windows and Fedora.
