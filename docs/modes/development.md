# Development mode

**Build pressure, at engineering resolution.** Dense, exact, in the
_Technical_ style (blueprint grid, square edges, monospaced amber readouts,
straight segments and sample markers — nothing smoothed).

- Key metrics: CPU, RAM, disk read and write, network download, process count.
- Dashboard template: CPU total, process/thread/running counts, memory, disk
  I/O, network, CPU temperature, filesystem usage.
- Packs: Dev Monitor Rail, Right Rail, Network Strip, Bottom Bar.
- The Overview's process view (and the process inspector) is where a spike's
  process is found.
