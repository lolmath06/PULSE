# Personal mode

**Your everyday view, made yours.** A pleasant, balanced starting point in the
_Glass_ style, meant to be curated: every widget, the style and the layout
are yours to change.

- Key metrics: CPU, RAM, temperature, download.
- Dashboard template: Personal starter (summary strip, processor chart, memory
  and temperature rings, network, storage).
- Packs: System Summary Card, Minimal Transparent HUD, Tiny Stats, Left Rail.
- Save the look you build as your own style (Appearance → _Save current look_)
  and share a dashboard with _Export_ (no hardware identifiers in it).
