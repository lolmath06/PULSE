# Gaming mode

**Overlay-first. Read it in a glance.** Bold, compact, thermal- and
performance-focused, in the _Gaming_ style (chamfered cards, crimson and
amber, condensed heavy numbers).

- Key metrics: CPU %, GPU %, CPU °C, GPU °C, VRAM, RAM.
- Dashboard template: CPU and GPU rings, a temperature chart with colour bands,
  memory, video memory group, network.
- Packs: Gaming Corner (six-figure HUD), Tiny Stats, Thermal Strip, Top Bar,
  Minimal Transparent HUD, Tiny Thermals.
- Entering the mode locks every overlay (click-through, never focused) and
  keeps PULSE running when the main window closes — both switchable.

**No FPS.** PULSE has no real frame-rate source, so it shows none. Overlays are
safe desktop windows — no injection, no DirectX/Vulkan/OpenGL hooks. They sit
over windowed and borderless games; exclusive fullscreen hides desktop windows.
